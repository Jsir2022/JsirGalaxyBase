# 个人地产地图 C.2 交互与视觉重设计

## 目标

地产页应首先是一张地图，其次才是产权表单。地图占附近地皮工作区约 74%，操作按钮贴在地图内侧，右侧检查器只保留所选区块的状态、价格与主操作。设计效果图见
`docs/design-assets/personal-land-map-c2-concept.svg`。

## 从 ServerUtilities 保留与舍弃的交互

SU 的区块界面采用 15x15 地图主体和贴边工具：左键认领、右键放弃，Shift 切换区块加载/卸载，Ctrl 开启矩形批量选择，Tab 隐藏产权覆盖。它的优点是地图占比高、动作贴近地图、悬浮承载上下文。

个人地产当前只允许单区块操作，因此不复制批量选择和强加载。右键也不直接执行破坏性放弃动作，改成打开上下文菜单并继续使用精确确认框。

## 推荐快捷键

| 输入 | 动作 | 安全规则 |
| --- | --- | --- |
| 左键单击 | 选择一个区块 | 不直接认领 |
| 左键拖拽 | 平移地图 | 超过 4px 后不触发选择 |
| 鼠标滚轮 | 以鼠标为锚点缩放 | 近/中/远三级 |
| 右键单击 | 打开所选区块菜单 | 认领/放弃仍二次确认 |
| `F` | 定位玩家 | 等价于定位按钮 |
| `R` | 刷新当前视口 | 清理当前视口地形缓存并查询产权 |
| `+` / `-` | 放大/缩小 | 与地图按钮一致 |
| `Tab` | 临时隐藏产权覆盖层 | 松开恢复，不改变筛选或数据 |
| `Esc` | 先关闭菜单/弹窗，再退出页面 | 弹窗打开时地图不接收输入 |

不采用 SU 的 Shift 强加载和 Ctrl 框选，避免让未实现能力出现在交互暗示中。WASD 不绑定地图，防止终端输入焦点和玩家移动键冲突。

## 视觉结构

- 保留终端左侧导航和顶栏；业务摘要压缩为一行状态胶囊。
- `附近地图 / 我的地皮` 使用窄页签；同一行显示关键操作提示。
- 地图横向填满左侧工作区，不再强制为居中的小正方形。地形瓦片可以非正方形裁切视口，但每个区块在地图坐标中仍保持正方形。
- `+ / - / 定位 / 刷新 / 图层` 采用 SU 风格的地图内悬浮竖栏。
- 图例成为地图底部半透明状态条，同时显示缩放级别、视口尺寸和鼠标区块。
- 玩家标记改成 40px 左右的水滴定位针，内部显示玩家头像，尾部或外部小箭头表示朝向；远级缩放时最小保持 22px，避免缩成难辨识三角形。
- 普通区块网格透明度降到约 15%；只有产权外边界、当前区块和选择边界保持高对比。相邻同产权内部边界不绘制。

## 悬浮信息

悬浮卡片固定使用服务端事实和客户端地形事实，不拼接无法验证的信息：

1. 区块坐标与方块范围；
2. 距玩家的 Chebyshev 区块距离；
3. 地形加载状态，以及可可靠取得时的生物群系；
4. 未认领、本人产权、他人产权、保留区或禁用维度；
5. 所有者公开显示名或脱敏标识；
6. 产权编号、版本、保护模式；
7. 认领费用、系统参考地价、挂牌价和最近过户价；
8. 当前是否可操作及不可操作原因。

价格必须区分语义：

- `claimCost`：本次向系统认领需要支付的确定金额；
- `assessedValue`：系统估值，仅供参考，不是成交承诺；
- `listingPrice`：产权人当前固定价挂牌金额；
- `lastTransferPrice`：最近一次真实过户金额。

Batch C.1 尚无这些价格字段。合同接入前统一显示“未启用 / 未挂牌 / —”，客户端不得生成示例价格。效果图中的 `12,800 GT` 和 `15,600 GT` 仅用于展示未来信息层级。

## 数据与实施边界

- 地形、生物群系、加载状态来自当前客户端世界；产权、所有者、版本、可操作性和价格必须来自服务端快照。
- 如下一批只做视觉优化，可以先扩大地图、重做标记和丰富已有悬浮字段；价格区域显示未启用。
- 如下一批同时接入价格，需要先定义服务端定价规则、扣款事务、产权操作日志和失败回滚，不能只增加 UI 字段。
- 现有半径 7 认领限制、视口中心限幅、幂等 requestId、版本校验和确认框保持不变。

## Batch C.2 实施结果（2026-08-24）

- 地图已改为自适应矩形视口，以最长边固定显示近 9、中 15、远 31 个正方形区块；短边按实际比例显示，边缘瓦片使用正确 UV 裁切，不拉伸地形。
- 地图工具、紧凑图例、视口状态、真实皮肤头像定位针、朝向箭头、右键菜单与快捷键已进入同一地图组件。右键选择新目标时先等待服务端返回该目标的权威快照，再恢复菜单。
- 悬浮卡使用客户端已加载区块的地形/生物群系和服务端产权事实；未本地化的生物群系只显示 ID。所有者保持“你 / 其他玩家 / —”，不公开 UUID。
- 检查器明确显示价格能力尚未启用，没有把效果图示例值写入客户端或服务端合同。
- 本批没有改动地产 payload、PostgreSQL schema、银行、定价或挂牌模型。

## 高 GUI Scale 比例修正（2026-08-27）

实机 1680x840 截图对应的地产工作区约为 350x193 逻辑像素。旧实现仍用普通尺寸下的
`160px` 检查器下限、`22px` 地图按钮和 `34px` 玩家针下限，经过 GUI Scale 放大后分别造成
检查器占三分之一、工具栏过宽和头像覆盖多个区块。

- 页面布局以比例为主：检查器限制在工作区约 24%，地图保持至少 74%，高 GUI Scale 不再走
  “检查器占三分之一”的特殊分支。
- 摘要、页签与快捷提示压缩到 32 逻辑像素内，地图使用全部剩余高度。
- 玩家针按当前区块像素宽度计算，中倍率约为一个区块的 90%，取消 34px 硬下限；远倍率仍保留
  最小可辨识头像和方向。
- 工具栏、状态条和悬浮卡均使用紧凑或地图相对尺寸，避免固定大尺寸在 GUI Scale 4 下再次放大。
- 检查器改用独立信息行，不再依赖语言文件中的 `\n` 转义；价格仍只显示未启用占位。
